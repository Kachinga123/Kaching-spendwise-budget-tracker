
# SpendWise - Personal Budget Tracker

## 1. Project Overview

SpendWise is a personal budget tracking web application designed to help users manage their finances, record daily expenses and monitor their spending.

The application provides a simple dashboard where users can set a budget, add expenses, organize transactions into categories and view their remaining balance.

## 4. Technologies Used

- HTML5 – Provides the structure of the application.
- CSS3 – Handles styling and responsive layouts.
- JavaScript – Provides interactive functionality and calculations.
- Browser Local Storage – Stores budget and expense records.
- GitHub – Hosts the project source code.
- Netlify – Publishes the application online.

## 5. Main Features

### Budget Management
Users can enter and save their total budget.

### Expense Tracking
Users can record expenses by providing the expense name, amount, category and date.

### Expense Management
Users can view recorded expenses and delete unwanted records.

### Automatic Calculations
The dashboard automatically calculates total expenses and the remaining balance.

### Expense Categories
Expenses are organized into:
- Meals and groceries
- Travel and bus fare
- House rent and housing
- Entertainment
- Utilities
- Other

### Local Storage
The application saves budget and expense records in the browser so that they remain available after refreshing the page in the same browser.

### Responsive Design
The interface adjusts to different screen sizes, including desktop, tablet and mobile devices.

## 6. How to Use SpendWise

1. Open the SpendWise website.
2. Enter your total budget.
3. Click Save Budget.
4. Enter an expense name and amount.
5. Select an expense category.
6. Select the expense date.
7. Click Add Expense.
8. View the expense in the records table.
9. Monitor your dashboard and category totals.
10. Use the Delete button to remove an expense.

The application currently uses browser Local Storage to save information. Therefore, data is stored locally in the user's browser and is not automatically synchronized across different devices.
